# @ccgrapher/site

The static site. One `index.html`, no framework, no build step, no dependencies.

```bash
pnpm --filter @ccgrapher/site dev   # http://localhost:4173
```

The images in `assets/` are copies of the renders in the repository's `docs/` directory, which
are themselves generated by `tools/rasterize.mjs`. When those change, copy them across again
rather than editing them here.

Private and unpublished. Deployment is a plain file copy to static hosting.
